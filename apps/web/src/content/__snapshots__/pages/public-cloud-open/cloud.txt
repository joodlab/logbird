Questions
Cloud questions, answered as far as we can today.
When can everyone sign up?
We haven't set a date. Logbird Cloud is in early access: sign-ups are limited to invited teams while we onboard them. Request access and we'll be in touch.
Where will my data be stored?
We'll publish the hosting region with the Cloud's launch terms. Ask us before you send production data. If your data must stay in a particular place, self-host Logbird.
Is the cloud a different product?
No. It runs the same codebase as the self-hosted version. One difference is already decided: Logbird Cloud won't offer a free-form SQL console. The guarded SQL WHERE mode in the explorer is in both.
Can I move between self-host and cloud?
Not with a tool or a guide today. Both run the same codebase, but there's no migration tool and no documented migration path yet.
How much will it cost?
Self-hosting is free under the MIT licence. Logbird Cloud is free during early access; its pricing after that will be published before billing starts.
Will there be an SLA?
Not during early access. There are no published service levels or limits yet.
What do you do with the email I give you?
We store it to contact you about Logbird. No trackers. See the privacy policy.
Want early access?
Self-host Logbird today, or request access to Logbird Cloud, where sign-ups are limited to invited teams for now.
