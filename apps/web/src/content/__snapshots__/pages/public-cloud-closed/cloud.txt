Questions
Cloud questions, answered as far as we can today.
When does Logbird Cloud open?
We haven't set a date. People on the waitlist hear first.
Where will my data be stored?
Not decided yet. We'll publish the hosting region before the cloud opens. If your data must stay in a particular place today, self-host Logbird.
Is the cloud a different product?
No. It will run the same codebase as the self-hosted version. One difference is already decided: Logbird Cloud won't offer a free-form SQL console. The guarded SQL WHERE mode in the explorer is in both.
Can I move between self-host and cloud?
Not with a tool or a guide. Logbird Cloud will run the same codebase, but there's no migration tool and no documented migration path yet.
How much will it cost?
Self-hosting is free under the MIT licence. Logbird Cloud is free during early access; its pricing after that will be published before billing starts.
Will there be an SLA?
There are no published service levels or limits yet.
What do you do with my waitlist email?
We store it to contact you about Logbird. No trackers. See the privacy policy.
