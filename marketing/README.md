# Marketing media and drafts

Nothing in this folder is automatically posted. The owner publishes reviewed material.

- `media/staydesk/`: compact, reviewed WebP screenshots from the real console, using isolated fictional Acme / StayDesk fixtures. Both themes and phone views are included.
- `../docs/media/`: the README GIF and matching WebM walkthrough, shared with the marketing site.
- `copy/`, `devlog/`: publication drafts. Historical captures have been removed; drafts that need additional evidence must be recaptured before publication. A new screenshot is not evidence for an old performance or deployment claim.
- `tools/`: capture instructions.

Use [the media guide](../docs/media/README.md) to reproduce assets. Keep a small curated set in normal Git; do not commit raw video, session files, API keys, personal paths or customer data. Inspect every still and the complete recording before publishing. Unreviewed QA output belongs in ignored `output/` or `.tmp/` directories.
